# Врата сортировки: Люди • Ценности • Процессы • Вещи • Время • Место

<small>← [Референция](10c_reference.md) · [Далее: Размер блока →](10e1_chunk-size.md)</small>

🟢 Базовый · ⏱ 6 мин

*На совещании один запомнил «кто что сказал», другой — «какие решения приняли», третий — «когда дедлайны». Все были на одном совещании. У каждого свои «врата» — фильтр, пропускающий только один тип информации.*

<details>
<summary><b>Кратко</b></summary>

- 6 фокусов внимания: Люди, Ценности/Результаты, Процессы, Вещи, Время, Место
- Каждый человек замечает «своё» первым — остальное проходит мимо
- Для эффективной коммуникации начинайте с фокуса собеседника
- Подстройка: используйте слова из «мира» собеседника

</details>

*На что человек обращает внимание в первую очередь?*

Эта метапрограмма определяет, какой аспект ситуации человек замечает и считает важным прежде всего. Как будто информация проходит через «ворота», которые пропускают только определённый тип.

| Фокус | Ключевой вопрос | На что обращает внимание |
|-------|-----------------|--------------------------|
| **Люди** | Кто? | Кто участвует, отношения, чувства |
| **Ценности / Результаты** | Зачем? | Смысл, значимость, итоги, выгода |
| **Процессы / Процедуры** | Как? | Последовательность, методы, шаги |
| **Действия / Вещи** | Что? | Инструменты, ресурсы, конкретные операции |
| **Время** | Когда? | Сроки, длительность, моменты |
| **Место** | Где? | Пространство, локация |

**Почему некоторые фокусы объединены:**

- **Ценности / Результаты** — оба отвечают на «Зачем?». Ценности — абстрактный смысл («это важно для меня»), результаты — конкретный итог («что получу»). Разные грани одного вопроса о значимости.

- **Процессы / Процедуры** — оба отвечают на «Как?». Процесс — общая последовательность («как это происходит»), процедура — формализованные шаги («как делать по инструкции»). Разная степень формализации одного фокуса.

- **Действия / Вещи** — оба отвечают на «Что?». Действия — что делать, вещи — чем делать. Операции и инструменты для них неразрывно связаны.

### Пример: «Как прошёл отпуск?»

Один и тот же отпуск шесть человек опишут по-разному:

| Фокус | Ответ |
|-------|-------|
| **Люди** | «Познакомились с классной семьёй из Питера, дети подружились» |
| **Ценности** | «Наконец-то перезагрузился, понял что действительно важно» |
| **Процессы** | «Прилетели, заселились, первые дни на пляже, потом экскурсии...» |
| **Вещи** | «Отель 4 звезды, бассейн, шведский стол, номер с видом на море» |
| **Время** | «Две недели, первые три дня привыкали к климату» |
| **Место** | «Турция, Анталья, прямо на берегу, рядом горы» |

> **Попробуйте:** Опишите своё утро тремя способами: через людей (с кем общались), через процессы (что делали), через результаты (чего достигли). Какое описание далось легче всего? Это ваши «врата».

### Как распознать

Задайте открытый вопрос и слушайте, о чём человек говорит **первым**. Это и есть его «ворота».

### Применение

| Роль / задача | Типичный фокус |
|---------------|----------------|
| HR, менеджер команды | Люди |
| Лидер, стратег | Ценности / Результаты |
| Инженер, аналитик | Процессы / Процедуры |
| Закупщик, логист | Вещи / Действия |
| Проектный менеджер | Время |
| Организатор мероприятий | Место |

**Для коммуникации:** Начинайте разговор с того аспекта, который важен собеседнику.

## Подстройка

### Речевые паттерны

| Фокус | Примеры слов и фраз для подстройки |
|-------|-----------------------------------|
| **Люди** | Коллеги, друзья, [имена], [фамилии], команда, партнёры, клиенты, «кто участвует», «с кем работаем» |
| **Ценности / Результаты** | Качество, успех, удовольствие, доверие, победа, выгода, достижение, «имеет значение», «важно», «ценно», «для достижения цели», «чтобы получить отдачу», «открылась новая возможность» |
| **Процессы** | Переделали, закупили, опросили, планируем, определяем, продадим, «делая поэтапно», «продвигаясь вперёд», «в процессе работы» |
| **Процедуры** | Во-первых, во-вторых..., сначала... затем..., после того как..., последовательно, поэтапно, «продвигаясь шаг за шагом», «согласно инструкции» |
| **Действия** | Движение, создание, общение, инструктаж, переговоры, планирование, учёт, участие, понимание, выполнение |
| **Вещи** | Компьютер, визитка, телефон, кресло, оборудование, инструменты, ресурсы, материалы |
| **Время** | В 14:00, через десять минут, понедельник, позавчера, на этой неделе, в будущем сезоне, «секундочку», «когда именно» |
| **Место** | В центральном офисе, на складе, здесь, там, у клиента, в комнате переговоров, на рабочем месте, у окна, «где именно» |

### Пример: одна ситуация — разные фокусы

Описание командировки для разных собеседников:

| Фокус | Как рассказать |
|-------|----------------|
| **Люди** | «Познакомился с Ивановым из отдела закупок, очень толковый человек. Петров тоже был, помнишь его?» |
| **Ценности** | «Поездка была ценной — укрепили партнёрство, получили важные договорённости» |
| **Результаты** | «Подписали контракт на 2 млн, договорились о скидке 15%» |
| **Процессы** | «Съездили, познакомились с поставщиками, обсудили условия, договорились об оплате» |
| **Процедуры** | «Сначала встретились в офисе, затем поехали на производство, после этого подписали документы» |
| **Действия** | «Была поездка, знакомство, обсуждение, заключение договора» |
| **Вещи** | «Офис у них современный, оборудование новое, образцы продукции качественные» |
| **Время** | «Выехали в понедельник в 8 утра, переговоры заняли 3 часа, вернулись к вечеру среды» |
| **Место** | «Были в их московском офисе на Тверской, потом на производстве в Подольске» |

> **Попробуйте:** Расскажите кому-то о вчерашнем дне, специально фокусируясь только на людях — кто что сказал, кто как отреагировал. Непривычно?
