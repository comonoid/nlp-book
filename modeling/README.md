# Моделирование

Раздел о том, как извлекать структуру навыков, убеждений, ценностей и идентичности через интервью и анализ транскриптов.

## Материалы раздела

1. **[Работа с неосознанной компетенцией](unconscious-competence.md)** — главный барьер моделирования и 8 техник его обхода. Читать первым.

2. **[Протокол интервью: навык](interview-protocol.md)** — 6 фаз интервью для моделирования навыка (T.O.T.E. → микростратегии → метапрограммы → убеждения/ценности → верификация).

3. **[Протокол интервью: убеждения, ценности, идентичность](interview-beliefs-values.md)** — 6 фаз интервью для моделирования системы смыслов (ценности → каскад убеждений → идентичность и роли → связи и конфликты).

4. **[Протокол анализа транскрипта](transcript-analysis.md)** — 6 проходов по расшифровке интервью + два шаблона итоговых моделей.
