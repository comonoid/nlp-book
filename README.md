## Структура

```
Цикл обучения (понимание стадии освоения)
    │
    └── на каждой стадии работает T.O.T.E.

T.O.T.E. (петля обратной связи)
    │
    ├── T1 → Спецификация цели (9 пунктов)
    ├── O (операции)
    ├── T2 → ОСВК (8 принципов)
    └── E (выход)

Метапрограммы (фильтры восприятия)
    │
    └── влияют на все этапы T.O.T.E. и коммуникацию

```
