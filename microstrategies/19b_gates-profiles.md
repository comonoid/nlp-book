## Комплексная тренировка

### Упражнение «Шесть линз»

Возьмите одну рабочую ситуацию и опишите её шесть раз, каждый раз через один фокус:

| Фокус | Ваше описание |
|-------|---------------|
| **Люди:** Кто участвует? Что чувствуют? Какие отношения? | |
| **Ценности:** Зачем это нужно? Какой результат? Что важно? | |
| **Процессы:** Как это происходит? Какие этапы? Где узкие места? | |
| **Вещи:** Что используется? Чего не хватает? Какие ресурсы? | |
| **Время:** Когда? Сколько длится? Какие сроки? | |
| **Место:** Где? Как среда влияет? Какой контекст? | |

Обратите внимание:
- Какие описания получились длинными и детальными? — это ваши сильные фокусы
- Какие — скудными или формальными? — это зоны роста
- Какие *дали неожиданную информацию*? — это то, что вы обычно пропускаете

> **Попробуйте:** Возьмите одну рабочую ситуацию и опишите её шесть раз — каждый раз через один фокус (Люди, Ценности, Процессы, Вещи, Время, Место). Какое описание получилось самым скудным? Это ваша зона роста.

### Упражнение «Ротация фокуса на совещании»

На следующем совещании осознанно переключайте фокус:
- Первые 5 минут слушайте через «Люди»: кто говорит, как реагируют, кому некомфортно
- Следующие 5 минут — через «Ценности»: о чём на самом деле спор? Какие ценности конфликтуют?
- Ещё 5 минут — через «Процессы»: как идёт обсуждение? Где буксует? Какой шаг пропустили?
- И так далее

Это трудно делать в реальном времени — начните с ретроспективного анализа: после встречи пройдитесь по всем шести фокусам.

> **Попробуйте:** После следующего совещания сделайте ретроспективный анализ: пройдитесь по всем шести фокусам и запишите, что вы заметили через каждый из них. Что упустили в реальном времени?

### Упражнение «Недельный марафон»

Посвятите каждый день недели одному фокусу:

| День | Фокус | Практика |
|------|-------|----------|
| Понедельник | **Люди** | Каждое решение начинайте с вопроса «Кто?» |
| Вторник | **Ценности** | Каждое действие начинайте с вопроса «Зачем?» |
| Среда | **Процессы** | Для каждой задачи рисуйте последовательность шагов |
| Четверг | **Вещи** | Для каждого плана составляйте список конкретных ресурсов |
| Пятница | **Время** | Для каждой задачи оценивайте длительность и дедлайн |
| Суббота | **Место** | Замечайте, как среда влияет на всё, чем занимаетесь |
| Воскресенье | Рефлексия | Какой фокус дался сложнее всего? Что нового заметили? |

### Упражнение «Переводчик»

Возьмите одно и то же сообщение и «переведите» его для человека с каждым фокусом:

**Исходное сообщение:** «Нам нужно мигрировать базу данных на новый сервер»

| Фокус | «Перевод» |
|-------|-----------|
| **Люди** | «Петров отвечает за миграцию, Иванова тестирует, Сидоров координирует с клиентами. Клиенты будут нервничать — нужно предупредить» |
| **Ценности** | «Миграция снизит стоимость инфраструктуры на 40% и увеличит скорость ответа для пользователей» |
| **Процессы** | «Сначала делаем резервную копию, потом настраиваем новый сервер, переносим данные, проверяем целостность, переключаем трафик» |
| **Вещи** | «Нужен сервер с 64 ГБ RAM, pgdump, VPN-доступ к обоим серверам, скрипт миграции» |
| **Время** | «Бэкап — 2 часа, настройка — полдня, перенос — 4 часа ночью, проверка — утро следующего дня. Окно даунтайма: 01:00-05:00» |
| **Место** | «Старый сервер в дата-центре в Москве, новый — в облаке AWS eu-west-1. Задержка для российских пользователей может вырасти» |

Это упражнение одновременно тренирует все шесть фокусов и показывает, сколько информации даёт каждый из них.

> **Попробуйте:** Возьмите одно сообщение, которое хотите донести до команды, и «переведите» его для всех шести фокусов — как бы вы объяснили это человеку с фокусом на Людей? На Ценности? На Процессы? И так далее.

## Типичные комбинации и «слепые зоны»

Некоторые фокусы естественно сочетаются, создавая типичные профили с характерными «слепыми зонами»:

| Профиль | Сильные фокусы | Типичная слепая зона | Что упускает |
|---------|----------------|----------------------|--------------|
| **Технический лидер** | Процессы + Вещи | Люди | Команда выгорает, конфликты не замечаются |
| **HR / тимлид** | Люди + Ценности | Процессы + Время | Вдохновляет, но не структурирует; сроки плывут |
| **Стратег** | Ценности + Время | Вещи + Процессы | Видение красивое, реализация хромает |
| **Исполнитель** | Процессы + Время | Ценности | Делает быстро и чётко, но не то, что нужно |
| **Аналитик** | Процессы + Ценности | Люди + Место | Модель идеальна, но не учитывает человеческий фактор и контекст |

Если узнали свой профиль — вы знаете, какой фокус тренировать в первую очередь.

> **Попробуйте:** Определите свой профиль по комбинации сильных фокусов. Посмотрите на типичную слепую зону — и выберите один фокус из неё для тренировки на этой неделе.
